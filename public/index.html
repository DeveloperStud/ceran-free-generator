Deploy free on Cloudflare

  1. Push this repo to GitHub (already prepared as ceran-free-generator).
  2. Cloudflare Dashboard → Workers & Pages → Create → Connect to Git → select repo.
  3. Framework preset: None · Build: empty · Output: public · Deploy.
  4. (Optional) Add Worker with AI binding for FLUX on free neurons, or keep pure Pollinations static.

Or: npx wrangler pages deploy public --project-name=ceran-free-generator after wrangler login.
